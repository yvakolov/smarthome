# Smart Home

Smart Home is a standalone web application for creating projects and drawing precise building contours.

## Stack

Nx, Angular 22, Spartan UI, Tailwind CSS, Konva and `@lucide/angular`.

## Application

- Authentication layout with a simple sign-in form.
- Shell layout with a header and router outlet.
- Project manager for creating and opening browser-local projects.
- Editor layout with toolbar, canvas, command console and status bar. Navigation and inspector zones are hidden initially.
- Graphical contours, rectangles with staged dimensions and rotation, geometric inference and temporary points.
