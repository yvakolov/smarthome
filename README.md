# SmartBarn

Migration of the reviewed SmartBarn v5 contour prototype to an Nx + Angular 22 application.

The implementation is being added to this repository. Deployment target: GitHub Pages.

## Scope

- Standalone auth and shell layouts with lazy routes.
- Demo-only login: `juralab` / `juralab`. This client-side gate is not a security boundary.
- Project manager with browser-local persistence.
- Konva editor with graphical contours, rotated rectangles, inference and temporary points.
- Spartan UI, Tailwind CSS and `@lucide/angular`.

No backend or production authentication is included. Do not store sensitive data in this demo.
